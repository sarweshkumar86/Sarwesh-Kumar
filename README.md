# Sarwesh Kumar — Academic Portfolio Website

A complete, responsive Computer Science educator portfolio built using HTML5, CSS3 and vanilla JavaScript. Uses the exact portrait supplied by the user, and includes the supplied PDF resume.

## Open it locally

1. Extract the ZIP file.
2. Open `Sarwesh_Academic_Portfolio/index.html` in Chrome, Edge, Firefox or Safari.
3. No installation, build process, server, database, account or API is required. Google Fonts is an optional online enhancement; browser fallback fonts work offline.

## Files

- `index.html` — all website content and accessible navigation.
- `assets/css/style.css` — responsive layouts, academic colors and light/dark themes.
- `assets/js/main.js` — mobile navigation, theme toggle, scroll progress, navigation highlighting, project filters and reveal animations.
- `assets/images/sarwesh-portrait.png` — user's original uploaded photo.
- `assets/images/favicon.svg` — brand icon.
- `Sarwesh_Kumar_Resume.pdf` — uploaded resume, linked to Download CV buttons.

## Features

- Academic-first homepage and teaching philosophy
- Three degrees and teaching specialization
- Complete professional experience timeline
- Jury recognition and five listed certifications
- Original illustrated project-placeholder cards, with functioning category filters
- Responsive navigation and optional dark mode
- Accessible keyboard navigation and reduced-motion support
- Email, phone, location and resume download

## Important: verified facts and carefully qualified text

Content has been grounded in the provided resume. It lists **12+ years of overall professional experience**, not 12+ years of school teaching. Professional history is listed as in the original resume, including its dates, employers, degrees, certificates and 2026 MESC recognition. TGT/PGT are career targets, not claims of having held those posts; HOD experience has not been invented. Projects are presented as representative work categories; their illustrations are mockups, not fabricated project screenshots or live links.

## Updating it

- Edit words and links in `index.html`.
- Replace the image at `assets/images/sarwesh-portrait.png` to update the picture.
- Change colors in the `:root` CSS variables in `assets/css/style.css`.
- To add actual projects, replace the cards' placeholder visuals and add verified links/screenshots to the card's details.
- To change contact details, edit the `mailto:` and `tel:` links in `index.html`.

## Publishing to GitHub Pages

Upload the *contents* of the `Sarwesh_Academic_Portfolio` folder into a GitHub Pages repository root. In Settings → Pages, select the main branch and root folder. Wait for GitHub's publishing confirmation; do not upload the parent ZIP as the site root.
